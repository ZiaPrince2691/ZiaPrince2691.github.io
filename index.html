about

What I do

I'm a backend developer focused on building real-world web applications and APIs with Python. My work centers on designing REST APIs, modeling relational data, and layering in the pieces that turn a CRUD app into a proper backend system — caching, background workers, authentication, and real-time communication.

I've built four progressively more complex projects that trace that path: from a straightforward CRUD API to a real-time system running WebSockets, Redis, and Celery behind Docker. Each one is a real, deployed application with live API docs — not a tutorial clone.
